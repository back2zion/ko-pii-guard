# 한국어 자유 문장 이름 인식: 오류 원인과 알고리즘 재설계

확인일: 2026-10-10. 이번 작업은 원인 진단과 설계 연구다. 새 모델을 학습하거나
런타임을 교체하지 않았다. 아래 제안의 개선 효과는 아직 검증하지 않았다.

## 실제 오류를 단계별로 측정한 결과

v11의 이미 확인한 합성 평가 192문장·정답 이름 234구간을 다시 추론했다.
이번부터 이 자료는 진단용 개발 자료이며, 새로운 독립 평가 증거가 아니다.
이름별 정확 구간을 네 판정기 전체의 후보 합집합과 비교했다. 실제 공개 analyze 경로를
계측했고 가중치·입력·추론 코드·진단 도구 해시가 실행 중 변하지 않았음을 확인한다.

| 측정 | 구간 수 | 의미 |
|---|---:|---|
| 정확 정답 / 오탐 / 미탐 | 211 / 17 / 23 | 기존 보고서와 일치 |
| 점수 제한 전 정확 후보가 있는 정답 | 224 / 234 | 현재 argmax 경로가 제안할 수 있는 상한 |
| 점수 제한 후 정확 후보가 있는 정답 | 214 / 234 | 필터 입력 시점의 후보 상한 |
| 필터 후 정확 후보가 있는 정답 | 214 / 234 | 이번 자료에서는 필터가 정확 후보를 추가로 제거하지 않음 |
| 미탐: 정확 후보 자체 없음 | 10 | 필터·겹침 처리만 바꿔서는 복구 불가능 |
| 미탐: 후보 점수가 임계값 미달 | 10 | 점수 교정 또는 후보 판정 재설계 필요 |
| 미탐: 다른 구간과 겹쳐 병합에서 탈락 | 3 | 먼저 선택한 구간의 우선권 문제 |
| 오탐: 정답 이름과 겹치는 구간 | 13 | 좌표상 경계 불일치; 별도 의미 판단은 아님 |
| 오탐: 정답 이름과 겹치지 않는 구간 | 4 | 문맥·라벨 판단을 추가 조사할 대상 |

경계가 틀린 예측 하나는 오탐과 미탐에 함께 집계될 수 있다. 두 수치를 더해서
서로 다른 잘못된 문장의 수라고 해석하지 않는다. 후보 상한은 가능한 모든 BIOES
경로의 상한이 아니라, 현재 판정기들의 문자별 argmax를 디코딩한 결과의 합집합이다.

재현:

```bash

  --output benchmarks/results/name-context-v11-stage-diagnostic.json
.venv/bin/python -m pytest -q tests/test_name_context_stage_diagnostic.py
```

[진단 도구](../benchmarks/name_context_stage_diagnostic.py).
원문은 보고서에 복사하지 않는다. 이 도구는 모든 보조 판정기를 실행하는 단일 창
자료만 받으며 긴 문서를 같은 조건으로 진단한 것으로 보고하지 않는다.

## 확인한 구조 문제와 아직 검증할 가설

**확인한 사실:** `ner.py`는 문자별 BIOES 최대 점수를 선택한다. 전이 제약이 없어
I/E만으로도 구간이 시작될 수 있고, 구간 평균 점수는 경계 한 글자의 불확실성을
감출 수 있다. 필터는 기존 후보를 삭제할 뿐 새로운 시작·끝 좌표를 만들지 못한다.
기존 이름이나 주소와 겹치는 보조 후보는 점수가 높아도 버린다. 이번 미탐 3건은
정확 후보가 필터를 통과한 뒤 이 단계에서 사라졌다. 긴 문서에서는 보조 판정기와
필터가 비활성화되어 짧은 문장과 실제로 다른 알고리즘이 적용된다.

**검증할 가설:** 고정 E5 표현, 4096개 해시 문자 임베딩, 평균·최대 풀링에 의존하는
필터가 한국어 이름/조사 경계와 낯선 문맥에 충분하지 않을 수 있다. 그러나 이번
진단만으로 어느 표현이 원인인지 단정할 수 없다. 전이 제약·표현·학습 자료를 각각
바꾸는 제거 실험으로 구분해야 한다. CRF를 붙인다고 후보 누락이 자동 해결되지는 않는다.

**평가 문제:** 이름·문장·문맥 ID 분리만으로 자료 출처가 독립적이지는 않다.
동일 작성 방식의 합성 틀에서 이름을 바꾼 새 자료는 실사용 일반화의 증거가 약하다.
과거 회귀 3,222구간 보존은 필요한 안전장치지만 새로운 분야에서 오류가 없다는 뜻은 아니다.

## 제안 알고리즘과 반증 가능한 실험

주 실험은 **한 모델이 이름의 문맥과 시작·끝을 함께 채점하는 문자 구간 인식기**다.
이름 사전 추가, 특정 단어 금지, 새 보조 판정기 누적을 기본 개선 수단으로 삼지 않는다.

1. 문맥 인코더와 문자 표현에서 시작점·끝점·구간 내부·양쪽 문맥·길이 표현을
   결합해 `s(start, end, PERSON)`을 계산한다. 문자 좌표를 유지하되 형태소 경계는
   학습 특징으로 비교한다. 형태소 분석기가 제안하지 않은 이름도 허용한다.
2. 기존 argmax가 선택한 구간만 보지 않고 유효한 시작·끝 조합을 평가한다.
   최대 길이 L을 쓰면 후보 계산은 O(nL)이다. L은 학습 자료에서 정하고 잘린 정답 비율,
   장문 이름, 외국 이름을 별도로 검사한다. 범위를 벗어난 입력을 조용히 무시하지 않는다.
3. 서로 겹치는 후보는 먼저 나온 판정기의 권한으로 고르지 않는다. 공통 척도로
   학습한 점수를 사용해 비겹침 구간 집합의 총점을 최대화하는 동적 계획법을 비교한다.
   서로 다른 기존 판정기의 원시 softmax 점수를 바로 더하는 방식은 피한다.
   주소와 이름의 충돌도 공동 정책으로 평가하며 기존 주소 정답 보존을 검사한다.
4. 정답 구간에 더해 조사 포함·일부 글자 절단·옆 단어 결합을 어려운 음성 후보로
   학습한다. 같은 철자가 인물/일반명사인 문맥을 쌍으로 다루고, 이름만 바꿔도
   인물 판정이 유지되는지 검사한다. 모호한 문장의 정답을 임의로 만들지 않는다.
5. 인코더 고정/부분 미세조정(LoRA 포함)을 같은 자료·예산으로 비교한다.
   점수 교정과 임계값은 별도 calibration 분할에서만 정한다. 보류를 정답이나
   자동 마스킹 성공으로 집계하지 않는다. 심한 분야 변화에서의 처리 정책도 별도 설계한다.
6. 긴 문서에도 동일 판정기를 창마다 실행하고 원문 좌표의 후보를 합쳐 전역 선택한다.
   창 경계에서 잘린 이름, 문서 간 정보 혼입, 중복·누락을 재현 테스트로 검사한다.

| 실험 | 바꾸는 요인 | 확인할 가설 |
|---|---|---|
| A0 | 동결 v11 | 비교 기준, 재학습 없음 |
| A1 | 같은 문자 모델에 합법 BIOES 전이만 적용 | 경로 제약만으로 경계 오류가 감소하는가 |
| A2 | 공동 구간 채점 + 전역 비겹침 선택 | 후보 누락과 순서 의존 손실이 감소하는가 |
| A3 | A2의 문자 경계 특징 / 형태소 특징 각각 제거 | 한국어 경계 개선에 어떤 특징이 기여하는가 |
| A4 | A2의 인코더 고정 대 부분 미세조정 | 낯선 이름·문맥으로 전이되는가 |
| A5 | 최선 개발 후보에 대조 자료 포함/제외 | 동형어 문맥 일반화가 개선되는가 |
| A6 | 외부 한국어 모델 / 다국어 PII 모델 비교 | 구조 개발 대비 비용·실효성이 나은가 |

먼저 개발·검증으로 후보를 압축한다. 한 번에 여러 요인을 바꾸고 개선 원인을
단정하지 않는다. 각 학습 실험은 최소 3시드와 동일 예산, 문서 단위 bootstrap
구간을 보고한다. 임계값을 낮춰 늘어난 오탐을 가리고 재현율만 성과로 내세우지 않는다.

## 자료와 채택 기준

외부 자료는 출처·이용 조건·라벨 정책·원문 좌표를 검토하고, 공개 인물 NER와
개인정보 마스킹의 정책 차이를 정리한 뒤 사용한다. 논문 접근 가능성과 자료 재배포
허가는 다르다. 이번 작업에서 외부 데이터나 가중치를 내려받거나 편입하지 않았다.

문서·출처·작성자/생성기·분야 단위로 train/validation/calibration/test를 나눈다.
같은 문서의 변형과 같은 템플릿의 치환 문장은 분할을 넘지 않는다. 이름 철자 분리도
유지하되 동일 철자 인물/비인물 대조는 한 분할 안에서 수행한다. 자료 생성자와 모델
개발자가 같은 합성 자료만으로 최종 성능을 확정하지 않는다. 별도 사람이 검수한
한국어 외부 출처 평가를 확보하고 판정 불일치를 기록한다. 최종 test는 후보 선택 후
한 번 공개하며, 실패를 수정에 쓰면 전체 해당 자료를 개발로 전환한다.

채택 시 정확 구간 TP/FP/FN, 실제 별표 마스킹의 정답 전체 가림, 불필요하게 가린
문자 수, 인물 포함/비포함 문장의 오탐, 분야·이름 유형·문서 길이별 최악 성능,
CPU 지연·메모리를 함께 보고한다. 기존 정답 구간 손실 0·새 잘못된 구간 0 게이트를
유지하고, 기존에 전체 가려지던 민감 구간의 노출 재발도 별도 게이트로 추가한다.
전체 평균 개선으로 개별 회귀를 상쇄하지 않는다. 이 기준은 동결 자료에 대한 조건이지
모든 미래 입력에서 회귀가 불가능하다는 증명이 아니다.

자유 문장의 정보가 부족하면 사람이 읽어도 인물 여부를 확정할 수 없다. 따라서 임의의
모든 문장에서 미탐·오탐 0을 약속하지 않는다. 목표는 구조적 오류 원인을 제거하고,
측정한 사용 범위에서 두 오류와 불확실성을 함께 관리하는 것이다.

## 첫 구현 실험

A1의 합법 BIOES 전이 비교와 A2의 공동 문자 구간 채점·전역 구간 선택을
[첫 실험 보고서](name-span-experiment-v1.md)에 구현·검증했다. A3 이후의

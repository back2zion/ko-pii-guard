# 공동 문자 구간 모델 실험 v1

2026-10-10. [구조 연구](name-context-algorithm-research.md)의 A1 전이 제약과
A2 공동 구간 채점을 구현하는 첫 실험이다. 기본 API·E5 경로와 명시적으로 선택하는 v11은 유지한다.
이 문서의 최종 판정은 아래 실행 결과에 따른다.

## 구현과 고정한 실험 조건

[모델·구간 선택기](../scripts/name_span_experiment.py)는 문자별 BIOES argmax 대신
문자 구간의 시작·끝·내부 평균·길이를 함께 채점한다. 최대 32글자까지 모든 시작·끝
조합을 평가한다. 양방향 LSTM의 문맥 표현을 사용하므로 내부 평균만으로 순서를
판단하는 구조가 아니다. 동일 좌표 중복 후보를 정리한 뒤 동적 계획법으로 비겹침
구간의 점수 합을 최대화한다. 점수는 `logit - logit(threshold)`다. 빈 결과와 인접한
이름을 허용하고, 먼저 나온 판정기의 구간을 우선하는 규칙은 사용하지 않는다.
이 최적화는 학습된 점수에 대한 최적 선택이며, 실제 정답의 보장은 아니다.

E5 인코더는 고정하고 v11 주 판정기의 projection·문자 표현·LSTM에서 초기화했다.
학습 문자 집합의 각 문자는 별도 ID를 쓰고, 미지 문자는 UNK다. 초기 문자 가중치는
과거 해시 임베딩에서 복사하므로 초기 표현 자체가 충돌 문제를 해결한 것은 아니다.
구간 채점 층은 새로 학습한다. 보조 이름 판정기나 비인물 필터는 누적하지 않는다.
학습은 유효한 모든 구간의 이진 손실이며 정답 가중치 16, AdamW 0.001이다.

[훈련 도구](../scripts/train_name_span_experiment.py)는 v11 train 10,056행에서
동일 문장의 동일 주석을 중복 제거한 10,008문장과 validation 96문장을 사용한다.
같은 문장의 주석이 다르면 거부한다. 시드 20261010·20261011·20261012에 각각
6 epoch, batch 64, CPU 2스레드를 적용한다. 검증 정확 구간 F1 → 오탐 수 → 높은
임계값 → 이른 epoch 순으로 선택한다. 임계값 후보는 사전에 .3/.5/.7/.9로 고정했다.
세 모델을 전부 선택한 후 이미 살펴본 v11 평가 192문장을 진단용으로 실행한다.
이 192문장은 독립 평가로 보고하지 않는다.

32글자 제한은 이번 범위의 모든 정답을 포함한다. 제한을 넘는 학습 정답은 조용히
버리지 않고 실패시킨다. 이 실험이 더 긴 실제 이름까지 처리했다는 뜻은 아니다.
인코더 미세조정, 형태소 특징, 명시적 문맥 대조 손실, 별도 calibration 학습은 아직
구현하지 않았다. validation에서 선택한 sigmoid를 실제 정확도 확률로 해석하지 않는다.

[실험용 추론 연결부](../scripts/name_span_adapter.py)는 매 창에 같은 모델을 적용한다.
주소 토큰 예측과 이름 표현이 한 번의 인코더 실행을 공유하며 원래 주소 구간을 보존한다.
창 중복 후보는 양쪽 문맥이 더 많은 창을 선택하고 원문 좌표에서 전역 병합한다.
주소와 겹치는 이름은 허용하지 않는다. 이름·주소 공동 학습을 구현한 것은 아니다.
기본 패키지에서 이 연결부를 활성화하거나 새 가중치를 자동으로 불러오지 않는다.

## 평가의 분리

[공개 API 진단](../scripts/evaluate_name_span_public.py)은 기존 v11과 세 후보의
실제 analyze와 stars mask를 실행한다. 구간 정답 보존·새 잘못된 구간·이전에
가려지던 이름의 재노출을 각각 검사한다. 임계값 이중 적용을 피하려고 이름 전용
Guard의 score_threshold를 0으로 두고 모델 임계값을 그대로 사용한다.
외부 평가는 모든 비교 모델에 동일한 공개 analyze 경로를 적용한다.
외부의 가림 범위 수치는 구간 합집합이며 별도 stars 호출 결과와 구분한다.

외부 평가는 [공식 KLUE](https://github.com/KLUE-benchmark/KLUE)의
NER v1.1 dev 5,000문장 중 ID 해시 순서로 고정한 1,000문장이다. Wikitree 506문장,
NSMC 494문장, 정답 인물 908구간이며 인물 없는 문장은 433개다. PS만 KR_NAME으로
매핑하고 나머지 유형은 비인물로 둔다. 원문 공백과 문자 좌표를 바꾸지 않는다.
가중치·임계값을 전부 선택하기 전에는 외부 점수를 실행하지 않는다. 외부 점수로
세 모델 중 하나를 다시 선택하거나 임계값을 수정하지 않는다. 이름 판정기를
교체하기 전의 E5 기본 경로도 고정 임계값 .9의 비교 기준으로 함께 측정한다.

원문과 CC BY-SA 4.0 이용 조건은 공식 커밋
`3efd98708a40ff49251fddde35453f8fbb11f536`에 고정했다. 원문은 `/tmp`에 보관하며
저장소나 패키지에 복사하지 않는다. 결과에는 출처·해시·유형 매핑을 기록한다.
인물 경계 스트레스 평가이며, 공개·가상 인물도 포함되므로 비공개 개인정보 여부의
정책 평가가 아니다. 기반 모델이 과거에 KLUE를 보았는지는 확인되지 않았다.
원 기사·리뷰 그룹 정보가 없어 문장 단위 paired bootstrap 500회를 보고한다.
문서 단위 신뢰구간으로 부르지 않으며 문장 사이 의존성을 과소평가할 수 있다.

## 재현

데이터·코드·기준선 해시와 시드별 선택 결과는
[실험 manifest](../artifacts/name-span-experiment-v1/manifest.json)와
[학습 보고서](../artifacts/name-span-experiment-v1/report.json)에 기록한다.
실행한 모델·훈련 코드 사본도 같은 디렉터리에 보관한다. 기존 결과를 덮어쓰지 않도록
다른 출력 디렉터리를 지정한다. 학습 표현 캐시는 재현 가능한 임시 산출물이다.

```bash
.venv/bin/python -m pytest -q tests/test_name_span_experiment.py \
  tests/test_name_span_evaluation.py tests/test_name_span_adapter.py \
  tests/test_name_bioes_ablation.py
.venv/bin/python scripts/train_name_span_experiment.py \
  --output /tmp/name-span-reproduction
.venv/bin/python scripts/evaluate_name_bioes_ablation.py \
  --output /tmp/name-span-bioes.json
.venv/bin/python scripts/fetch_klue_name_evaluation.py
.venv/bin/python scripts/evaluate_name_span_external.py \
  --experiment /tmp/name-span-reproduction --output /tmp/name-span-external.json
.venv/bin/python scripts/evaluate_name_span_public.py \
  --experiment /tmp/name-span-reproduction --output /tmp/name-span-public.json
```

## 실행 결과

A1은 같은 검증 96문장의 동일 캐시·판정기·필터·임계값에서 BIOES 전이만 바꿨다.
정확 구간 TP/FP/FN은 A0 105/2/3 → A1 105/1/3이다. 이번 자료에서는 전이 제약으로
오탐 1개를 줄였지만 미탐을 복구하지 못했다. 주소 충돌을 포함한 공개 API 전체를
비교한 결과는 아니다. [A1 보고서](../benchmarks/results/name-span-v1-bioes-ablation.json).

공동 구간 모델은 실제 공개 API의 탐지와 별표 마스킹을 기존 진단 192문장에 실행했다.
이미 확인한 합성 자료이므로 독립 일반화 성능으로 해석하지 않는다.

| 모델 | TP | FP | FN | 기존 정답·가림 보존 및 새 오탐 차단 |
| --- | ---: | ---: | ---: | --- |
| v11 | 211 | 17 | 23 | 기준선 |
| seed 20261010 | 232 | 2 | 2 | 통과 |
| seed 20261011 | 231 | 2 | 3 | 통과 |
| seed 20261012 | 231 | 3 | 3 | 새 잘못된 구간 1개로 탈락 |

첫 후보는 검증 자료에서 epoch 3, threshold 0.7을 선택했다. 외부 평가로 재선택하지
않는다. 세 후보 모두 실제 별표 마스킹에서 기존에 완전히 가리던 이름의 재노출은
없었다. 첫 후보에도 이름 끝 문자를 놓치는 경계 오류 2건이 남아 있다.
[공개 API 실행 보고서](../benchmarks/results/name-span-v1-public.json).

새 테스트 25개를 포함한 실제 NER·v11 전체 테스트는 1,422개 통과했다.
전역 최적 구간 선택을 완전 탐색과 대조하고, 원문 좌표·단일 문자·주소 충돌·
긴 문장 창 병합·실제 별표 마스킹·인코더 한 번 실행을 검증했다.
새 공동 구간 모델의 과거 전체 회귀 자료 보존을 검증한 결과는 아니므로 런타임
채택 근거와 구분한다. 기본 모델과 배포 런타임은 교체하지 않았다.

## 외부 검증과 최종 판정

수정·후보 선택에 사용하지 않은 고정 KLUE 1,000문장(인물 구간 908개)에
모든 후보를 같은 실제 공개 analyze 경로로 실행했다. 외부 결과로 임계값을
재조정하거나 좋은 시드를 다시 선택하지 않았다.

| 모델 | TP | FP | FN | 정확 구간 F1 |
| --- | ---: | ---: | ---: | ---: |
| 기본 E5 참고값 | 765 | 126 | 143 | 85.05% |
| v11 | 635 | 179 | 273 | 73.75% |
| seed 20261010 | 481 | 220 | 427 | 59.79% |
| seed 20261011 | 501 | 139 | 407 | 64.73% |
| seed 20261012 | 502 | 164 | 406 | 63.79% |

세 후보 모두 외부 회귀 게이트에서 탈락했다. v11이 맞히던 정확 구간을 각각
176/162/161개 잃었고, 기존에 전체 가리던 이름의 구간 합집합 coverage를 각각
185/171/170개 잃었다. 이 외부 coverage는 별도 stars 실행이 아닌 analyze 구간
합집합으로 계산했다. 비인물 433문장에서 오탐이 있는 문장은 v11 49개,
새 후보 각각 84/60/64개다. 첫 후보의 v11 대비 F1 차이의 문장 bootstrap
95% 구간은 −16.77~−11.44%p다. 모든 실행에서 동결 입력 해시 변경은 없었다.
[외부 전체 보고서](../benchmarks/results/name-span-v1-external.json).

**판정: 세 후보 모두 런타임 채택 거부.** 기존 합성 진단의 개선은 외부 일반화
개선으로 이어지지 않았다. 구간 전역 선택은 점수 충돌을 풀지만 학습 데이터와
표현의 분포 차이를 해결하지 못했다. 인코더 고정, 합성 데이터 편중, 새로운 구간
채점기의 적응 부족은 다음 제거 실험으로 구분할 가설이며 이번 결과만으로
각 원인의 기여도를 확정하지 않는다. v11 역시 이 외부 자료에서 기본 E5보다
낮으므로 v11을 기본값으로 승격할 근거가 없다.

다음 연구 우선순위는 출처가 다른 개발 자료 확보, 기본 E5를 대조군으로 둔
인코더 적응·문맥 대조 학습의 제거 실험이다. 이번 KLUE 결과를 수정이나 선택에
사용하면 해당 자료는 개발 자료로 전환하고 새 외부 최종 평가를 확보해야 한다.
외부 데이터는 공개·가상 인물도 포함하고 기반 모델의 사전 노출은 확인되지 않아
비공개 개인정보의 실사용 정확도나 인물 마스킹 정책 정확도를 뜻하지 않는다.

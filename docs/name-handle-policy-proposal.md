# 별명·핸들 정책안 (제안, 곽두일 확정 전)

공통 기준: 문자열이 **해당 문맥에서 개인을 지칭하는 이름 대용의 별칭으로 쓰였는가**. 사람에게 쓰이는 단어라는 이유만으로 보호하지 않는다.
확정 전까지 이 안은 구속력이 없으며, 확정되면 **영향받는 모든 사례를 같은 지침으로 재판정**한다(불일치 사례만 고치지 않음).

| 질문 | 판정 기준 (제안) |
|---|---|
| 일반어 애정 호칭("애기", "공주님") | 일반적인 호칭·묘사는 기본 제외. "내 닉네임은 공주님", "연락처에 애기라는 이름으로 저장"처럼 별칭으로 쓴다는 근거가 있으면 보호. 짧은 문맥으로 구분되지 않으면 `insufficient`. |
| 자녀 이름 + 친족어("민수엄마") | 닉네임·활동명·개인 식별 별칭으로 쓰이면 전체 별칭을 보호. "민수의 엄마가 왔다" 같은 단순 친족 관계 표현은 별명으로 추가하지 않고, 그 안의 실명은 기존 이름 정책으로 별도 처리. |
| 태명 | "태명은 튼튼이예요"처럼 태명이라고 명시되거나 문맥상 확인되면 보호. 같은 단어의 일반 용법은 탐지하지 않음. |
| 외모 묘사·비하어 | 호의성·비하성과 무관하게 특정인의 별칭으로 쓰이면 보호. 단순 외모 묘사·일회성 욕설은 별명으로 추가하지 않음. 근거가 부족하면 `insufficient`. |
| 개인/공용 계정을 알 수 없는 핸들 | `insufficient` 유지. 문맥 부족을 양성·음성으로 강제하지 않는다. |

원래 출처 라벨(예: "개복치"가 KDPII에서는 PS_NICKNAME)에 맞추려고 판정을 고치지 않고, 원문과 확정 정책으로 판단한다.

# 이름 인식 회귀 방지 계약

2026-10-10. 오탐 감소가 기존 이름의 미탐 증가를 상쇄할 수 없다.

## 채택 조건

- 동결 기준선이 정확히 찾은 **각 이름 구간**을 보존한다. 전체 TP 수가 같아도
  특정 이름을 잃으면 실패한다.
- 새 잘못된 구간을 추가하면 실패한다. 전체 FP 수의 감소로 상쇄하지 않는다.
- 기존 비인물 회귀 문장은 실제 `analyze`와 `mask`에서 모두 보존한다.
- 새 평가에서 비인물 오탐이 증가하면 실패한다. 수정 대상 지표의 개선도 별도로
  요구한다. v6 비인물 수정은 비인물 오탐 감소, v7 미탐 수정은 기존 9건 해결과
  새 평가의 구간별 회귀를 검사한다. 미탐 개선이 새 오탐을 상쇄할 수 없다.
- 체크포인트 선택 전에 데이터·코드·기준 모델 해시를 기록한다. 선택에는 개발·검증
  자료만 사용한다. 새 평가에서 실패하면 해당 자료를 개발 자료로 전환하고 다음 평가를
  따로 만든다. 평가 결과를 보고 같은 평가에 맞춰 체크포인트를 다시 고르지 않는다.

`tests/test_name_context_nonregression_gate.py`는 TP/FP 합계만 좋아지고 특정 이름이
사라지는 경우를 검사가 거부하는지 확인한다. 137개 기존 정답 문장과 추가 역할 문장의
정확 구간·별표 마스킹은 각각 `test_name_context_no_recall_regression.py`와
`test_name_context_role_regression.py`에 고정했다.

## 탈락한 실험

- v4: 기존 비인물 12건은 해결했지만 새 평가에서 기존 정답 이름 8개가 사라졌다.
  채택하지 않는다. [v4 기록](name-context-v4-evaluation.md).
- v5 문자 판정기: 검증 자료의 기존 정답 1개를 잃어 체크포인트 선택에서 탈락했다.
  새 평가는 실행하지 않았다.
- v5 후보 판정기: 기존 v3 문자 가중치를 그대로 유지했지만 새 평가에서 역할 문장의
  이름 ‘온화’를 제거했다. 개별 구간 검사에서 탈락했다. 이 문장은 별도 회귀 테스트로
  고정했으며 당시 모델에서 실패를 재현했다.
- v8: 기존 미탐 6건·오탐 4건을 해결하고 1,378개 테스트를 통과했지만 새 평가에서
  기존 정답 1개를 잃어 탈락했다. [원인과 후속 구조 수정](name-context-v9-evaluation.md).
- v6 첫 학습: 개발 비인물 오탐 1건이 남아 선택 조건을 만족하지 못했다.
  새 평가는 실행하지 않았다.

후속 v6 재학습은 새 평가의 기존 정답 225개를 보존하고 비인물 오탐 8→0개로
통과했다. 전체 테스트 1,354개도 통과했다. [선택 모델 결과](name-context-v6-evaluation.md).
후속 v7은 기존 미탐 9건을 개별 테스트로 고정해 모두 해결했다. 새 평가에서도 기존
정답 224개를 보존하고 새 오탐 없이 이름 4개를 추가했다. 전체 1,366개 테스트가
통과했다. [v7 결과와 잔여 오류](name-context-v7-evaluation.md).
후속 v9는 기존 이름 보조 판정기를 보존한 채 개선 판정기를 추가했다. 기존 미탐
6건·오탐 4건을 모두 해결했고 전체 1,381개 테스트가 통과했다. 새 평가의 기존
정답 228개를 각각 보존하고 새 오탐은 0개다. [v9 결과](name-context-v9-evaluation.md).
후속 실험의 성공 여부는 실제 평가 보고서와 CI 결과로 판단한다. 이 계약은 유한한
회귀·평가 자료에 대한 조건이며 모든 실제 문장의 무오류를 보장하지 않는다.

v10 후보는 기존 미탐 5개·오탐 2개와 1,389개 테스트를 통과해도 새 평가의
기존 이름 ‘공감’을 잃어 탈락했다. 회귀 구간을 별도 Red/Green 테스트로 고정하고
확인한 자료 전체를 개발로 전환했다. 후속 v11은 필터를 확대하고 어려운 표본을
재학습하며 강화된 이름 보존 기준을 적용한다. 전체 1,391개 테스트, 과거
3,049문장의 기존 정답 3,222개 보존·새 오탐 0개를 확인했다. 별도의 새 평가에서는
기존 정답 211개 손실·새 오탐 0개지만 미탐 23개·오탐 17개는 남는다.
[거부 원인·선택·재현·한계](name-context-v11-evaluation.md).

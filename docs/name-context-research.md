여기서는 방법과 적용 범위만 요약했다.

## 이번 실험의 선택과 한계

새 실험은 고정 E5 모델의 문맥 표현을 받아 문자별 BIOES를 예측하는 작은 양방향 LSTM
판정기다. 토크나이저가 `이상의`처럼 이름과 조사를 하나의 토큰으로 만들어도 문자 위치에서
경계를 학습할 수 있도록 한다. 이름 사전 점수 가산, 특정 단어 금지, 일괄 조사 제거는
사용하지 않는다. E5 본체의 파라미터는 고정한다.

이는 위 논문의 새로운 방법을 재현한 모델이 아니다. 특히 KLUEBERT-CRF,
Thunder-DeID의 토크나이저, K-NameDiag의 EDP, NRB의 적대적 학습, SoftLexicon의
어휘 임베딩 결합을 구현했다고 주장하지 않는다. 순차 판정기를 학습하는 것만으로 모든
문맥 오류가 사라진다는 근거도 없다. 실제 채택은 이 저장소의 별도 평가에 따른다.

과거 동결 이름 문맥 자료는 오류를 확인한 뒤 새 판정기의 학습에 사용하므로 이후에는
개발 자료다. 이전 보고서는 그대로 남기되, 새 판정기의 일반화 성능 증거로 재사용하지 않는다.
새 자료는 추론 전 생성하며 학습/검증/평가의 이름·문장·문맥 ID를 분리한다. 검증 분할로
체크포인트를 선택한 뒤 평가 분할을 한 번 실행한다. 합성 문장 틀 교차 자료는 독립적인
실사용 표본이나 사람 검수된 분야별 외부 자료를 대체하지 않는다.

논문이나 논문 PDF의 공개 접근 가능성이 데이터·가중치의 상업적 재배포 허가를 뜻하지
않는다. 이번 실험은 직접 작성한 합성 자료와 기존에 고정한 E5 모델만 사용하며,
위 논문의 데이터·가중치를 패키지에 포함하지 않는다.

## 반복 오류에 대한 후속 구조 연구

2026-10-10 실제 추론 단계별 오류 분석과 최근 문헌 추가 검토는
[알고리즘 재설계 연구](name-context-algorithm-research.md)에 기록했다.
고정 인코더·보조 판정기 누적 접근의 한계를 측정하고 공동 구간 채점과
출처가 분리된 평가로 전환하는 실험을 정의했다. 제안 모델의 개선 효과는 아직 검증하지 않았다.
